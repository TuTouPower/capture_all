# Task spec

## 背景

存在无消费者的导出、dead store/字段与孤儿实现：五个 exported API 在生产与测试引用图中零引用；deprecated `AgentStatus` 顶层字段仍在每次响应中生产且被测试反向固化；九个事件契约无生产者，Dashboard 与测试含不可达分支；四个 MCP `session` 工具 alias 是显式兼容面但无退出条件；`docs/blueprint/domain.md` 的禁用术语与现状冲突（部分见 t191）。

## 契约区

### 范围

- 删除确无消费者的死导出、dead store/字段、孤儿实现（有测试引用者先迁测试再删）。
- 移除或明确废弃 deprecated `AgentStatus` 顶层字段，同步测试不再反向固化。
- 明确九个无生产者事件契约的去留（删除或补生产者，禁止保留不可达分支）。
- 为四个 MCP `session` alias 明确退出条件（删除或记录移除计划）。

### 非范围

- 不删除仍被生产路径引用的代码。
- 不改变对外 MCP 工具语义（除非明确决策删除 alias）。
