# 项目交接记录

项目级交接放这里，不设 task 内交接。

本文件只保留**最新一节**（当前有效状态）；过时段落迁 `docs/archive/handoff.md`（只追加，不改写）。接手者先读本文件最新节，再按需下钻 task 或 archive。

每段交接使用以下格式：

```markdown
## YYYY-MM-DD HH:MM UTC+8 from_owner → to_owner

- 当前焦点：{task ID 或议题}
- branch：`{branch；无则写"无"}`
- head_commit：`{已存在的 commit SHA；无则写"无"}`
- 已完成：{列点}
- 未完成：{列点}
- 陷阱：{已知坑或反直觉处}
- 下一步：{接手者首要行动}
```
