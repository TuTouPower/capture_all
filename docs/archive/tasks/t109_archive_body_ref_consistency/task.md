# Task spec

## 背景

归档 body 路径去重改文件名后未回写 JSONL 中 `*_body_ref`，引用指向不存在文件。P1-12。

## 契约区

### 范围

- body 文件去重/改名后，JSONL（或清单）内对应 body_ref 字段更新为最终路径/文件名。
- 解压或读取归档时引用可解析到文件。
- 单测覆盖去重冲突样例。

### 非范围

- 不改压缩算法。
- 不改非归档导出路径。
