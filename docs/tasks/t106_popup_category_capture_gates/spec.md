# Task spec

## 背景

Popup 用户/导航/错误/Storage/Cookie 等开关仅写 tag，不关闭对应采集门控，UI 显示关闭仍采集。P1-9。

## 契约区

### 范围

- Popup 分类开关关闭时，对应类别事件在新 start 的 capture 中不写入（或 start 配置反映关闭）。
- 打开时恢复采集（回归）。
- 若某开关产品定义为「仅标签不控制采集」，须从 UI 移除误导或改文案；默认按「控制采集」实现。

### 非范围

- 不重做 popup 视觉设计。
- 不改 Dashboard 设置页（除共享配置字段必需）。
