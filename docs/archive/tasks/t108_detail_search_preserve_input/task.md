# Task spec

## 背景

详情时间线搜索 debounce 重绘后输入框被清空，用户无法连续输入过滤。P1-11。

## 契约区

### 范围

- 搜索 debounce 触发列表重绘后，输入框保留用户已输入字符串与光标合理位置（至少保留字符串）。
- 过滤结果仍随输入更新。

### 非范围

- 不改搜索算法/匹配语义。
- 不改其它页面搜索框。
